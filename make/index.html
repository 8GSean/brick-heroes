🧑‍🏫 For grown-ups

Setting up a class
  1. Open claude.ai/code (or the Claude app → Code) and connect the GitHub account that has this repository.
  2. Start a session on the brick-heroes repository. Claude reads CLAUDE.md, which explains the arcade rules (no losing, no reading needed, works with a controller), so students' wishes come out the same way.
  3. Each game is one file: games/<name>/index.html. A CONFIG block near the top holds easy-to-change numbers and colours.
  4. Ask Claude to put the work on a branch and open a pull request. When you merge it, the game updates on the website.
Tips for good wishes
  • One wish at a time. "Make the T-Rex purple" works better than ten changes at once.
  • Name the game: "In Drum Jungle, …"
  • Say how it should feel: silly, faster, bouncier, sparkly, louder.
  • Ask Claude to explain: "Show me the line that sets the jump height and explain it like I'm 8." It's a great way to start reading code.
  • Something broke? Just say what happened: "Now the truck falls through the floor." Claude can fix it or undo it.
  • Typing wishes is real reading, spelling and typing practice. Little ones can say the wish while a grown-up or older buddy types.
Bigger project ideas
  • "Make a new game in games/ where I'm a snowball that grows as it rolls. Follow the rules in CLAUDE.md and add it to the arcade page."
  • "Add a second player with another controller to Monster Truck Junkyard."
  • "Add a new station to the Learning Lab that teaches shapes and colours."
  • "Make a hat shop in Brick Heroes where I spend studs on silly hats."
